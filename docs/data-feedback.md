# 数据反馈方案

2026-10-06。当前实现：0.12.0。0.10.0 实际阶段进度条保留，空状态、恢复入口、登录提示与按需状态详情已落地；Coursework 现在仅有 Upcoming / Past，清除搜索保留分类。

## 已实现：刷新进度

- 全量刷新依次处理 Timetable、Coursework、Messages、Modules、Library 五项；单服务/更早消息为一项。
- 账户验证成功回调前进当前项的一半；数据读取、解析、缓存落地后结算整项。不可恢复或重试耗尽时也结算该项的失败处理。各项等权，表示处理阶段，不表示下载字节、耗时比例或所有数据成功更新。
- 只有状态变化才触发 200ms 平滑过渡。网络等待、2/5 秒重试等待期间不自行前进；重复认证不增加完成数，重试不改变分母。没有定时涨到 90% 的假进度。
- 顶部原品牌小字暂时显示 Updating Timetable · 1/5 或 Retry 1/2 · Timetable；不增加一行、不更改字号。结束后恢复品牌文字。
- 下拉手势继续工作，但隐藏旋转圈；常规刷新只使用顶部确定进度条。完成后最多停留 250ms 再隐藏，这只是退出显示，不延迟数据更新或请求完成。重新刷新独立计数，重建页面不重播已结束的进度。
- 失败任务也属于已处理任务，全部处理结束可到 100%；此时进度条用错误色并保留一次 Snackbar，不能理解为全部下载成功。登录过期或提前停止时，未执行项不补齐。退出取消请求/等待并清除进度，不补发成功反馈。
- 启动先读本地缓存，不伪装成网络进度；尚无 API 阶段时使用现有简短文字。设置页不触发刷新。Developer tools 的探查是独立调试流程，不计入常规任务进度。

## 已实现：状态与恢复入口

| 顺序 | 项目 | 展示与行为 |
| --- | --- | --- |
| 1 | 区分未加载、真实空列表、筛选为空 | 未同步不显示 No classes today；真实空列表用简短说明，保留 Library 原站空摘要；搜索为空提供 Clear search，不触发网络请求。Coursework 无搜索时显示 No upcoming deadlines / No past deadlines；清除搜索保留当前分类 |
| 2 | 失败与缓存恢复 | 失败后缓存继续可读，最终一次短提示；内容附近显示 Showing previous data + Retry，未加载失败使用 Couldn't load + Retry。重试过程中隐藏恢复行、重复触发受 busy guard 保护；正常页面不显示日志页脚 |
| 3 | 登录过期 | 保留缓存、停止认证重试；内容附近显示 Sign in，More 保留完整账户恢复入口且底部有小标记与无障碍文字。普通状态没有标记 |
| 4 | 部分更新与时间敏感信息 | More → Data status 按需显示五类数据状态和 Last updated（Warwick time），支持单资源重试/刷新；时间只在主动查看的详情出现，不作为正常页脚 |
| 5 | 截止日期边界 | 首页 Recently passed 统计缓存中最近七天的已过截止条目并打开 Coursework 的 Past；Past 说明过去不等于未提交。View all coursework 回到 All。筛选在切页保留、账户切换重置；不推断已交/未交 |

单资源重试的进度总数为一项：Timetable / Coursework / Messages / Library / Modules 各自调用原 GET 和账户验证。成功不会重报另一数据源的旧失败；全量刷新与原顺序、重试预算不变。更早消息失败单独记录，恢复操作沿用 before 游标；下拉始终读取最新消息，旧游标不可用时回退普通刷新。数据状态仅保存本轮错误/更新进度与已存在的缓存时间，不引入新接口或数据库字段。

先完成状态与恢复入口，再考虑后台刷新、通知和小组件。按项目约定不编写 UI Test；简单文案/布局靠构建与手机手动反馈，重试/取消等状态逻辑只做少量必要检查。
