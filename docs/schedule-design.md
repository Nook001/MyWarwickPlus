# Schedule 页面优化方案

2026-10-04。状态：用户选定连续列表，已在 0.7.0 原生 Schedule 实现。0.6.1 已先移除各页面的保存/同步页脚与 More 的诊断时间列表。

## 当前问题

顶部 Previous / Today / Next、周范围、七日选择器、Day / Week 切换、列表日期标题分别占据一行。选中日期在选择器和标题重复，信息层级被导航打断。单门课程又使用大卡片，模块代码、模块名、原条目代码、地点分别占行，课程之间有较多留白。

用户提供的官方截图更适合参考其日期分组和左侧时间列；不沿用花哨底图、每门课程的多余装饰与默认教师信息。

## 已选定并实现：连续日期分组列表

- 顶部保留紧凑 `Schedule` 标题和日期选择图标。正常列表不显示周范围、七个日期按钮或重复的当天大标题；离开今天后才显示 `Today` 返回操作。
- 默认从今天开始，按日期和开始时间展示缓存中的后续课程。日期仅放在分组标题，例如 `Tomorrow · 5 Oct`、`Tue 6 Oct`。根据用户补充，今天无课保留 `Today` 小标题，下面一个与课程组风格一致的平静底色容器，单行 `No classes today`。手动选定空日期也保留该日期标题与单行说明；其他未来空日期跳过。
- 同一天的课程共用平静、不透明的列表底色。行间细分隔线，课程间不加独立大圆角卡片、彩色圆点或粗时间轴。
- 时间列最小 48dp，通过 intrinsic 宽度随字体增长；开始时间 14sp、结束时间 12sp，全日项显示 All day。右侧课程名称 14sp，下一行原课表条目代码与地点 12sp。不同时重复模块代码和原条目代码。长名称最多两行省略、长地点换行，详情显示完整内容；不得为密度截掉时间或详情入口。
- 行高以内容决定，普通两行课程目标约 64–80dp。整行至少 48dp 可点击，右侧小箭头和点击反馈提示详情；大字体允许增长。
- 正在进行/下一节使用轻量 `Now` / `Next` 文字，普通课程颜色保持一致，不新增每门课程的色块或时间轴。全日项不参与 Now/Next 标记。重叠课程继续用文字提示；不能只凭颜色判断状态。
- 日期图标打开 Material 日期对话框，默认可键入 dd/MM/yyyy，支持切换日历；选择后从相应日期查看缓存记录，历史记录仍可查看。日期组件的 UTC 午夜值转换为日历日期后再使用 Warwick 日界，不把 UTC 直接当英国本地午夜。首次进入定位今天，离开起点/选其他日期后出现 Today 操作；切页、刷新及 Activity 状态恢复保留日期与滚动位置，正常冷启动回到今天。
- 跨午夜课程在每个覆盖日期出现，列表时间裁剪为该日 00:00–24:00 范围，并显示 Continues from previous day / Continues tomorrow；结束瞬间所在的空日期不多插入一条。详情保留原始完整起止时间，英国夏令时切换仍按 Europe/London 处理。
- 正常刷新继续下拉；失败和登录过期才出现必要提示。常态页面不显示缓存状态、同步日期或请求日志。

## 讨论过的备选：按周紧凑列表（未采用）

若希望每次只看一周，顶部仅保留一行 `‹ 5–11 Oct ›` 和返回 Today，下面仍为日期分组列表；移除七日选择器与 Day / Week 双重控制。周范围服务于切周，课程日期只在分组标题显示。

连续列表更适合“打开即可看后续课程”；按周列表更适合计划指定教学周。用户选定连续列表，原生主页面移除旧日/周模式和周导航，不额外维护一个模式菜单；历史与未来日期通过日期选择访问。按周草案保留为设计记录。

## 实现边界与验收

1. 独立 ScheduleScreen 与紧凑课程行，接入现有缓存与详情，沿用五套固定颜色；不新增 API。按日期懒加载，每个日期内共用列表底色。
2. 使用纯函数整理分组、跨午夜时间及日期组件转换；列表与选定日期状态提升到主页面，避免切页时重新初始化。
3. 验收普通/空日期、长名称/地点、320dp 与 1.8 倍字体、五套颜色；验证日期跳转/取消/返回今天、下拉刷新、切页/数据更新/保存状态恢复的列表位置。详细结果见 [validation.md](validation.md)。

交互草案中的课程与时间来自用户给出的官方截图，范围仅 2026-10-05 至 2026-10-09；不代表重新验证学校接口。姓名/教师、账户与认证信息未放入草案。日期选择/切周/详情均为本地预览，不请求学校 API。
