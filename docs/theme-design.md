# 颜色主题设计与实现

状态：已接入 Android 应用 0.6.0，并覆盖部署到测试手机。日期：2026-10-04。原生截图与自动化验收已完成；手机观感与滚动流畅性由用户继续复核。

每个主题是一套完整固定配色，直接决定画面的明暗。设置不提供浅色/深色/跟随系统开关，不读取系统明暗状态来转换已选配色，也不使用系统动态颜色覆盖主题。五套颜色共用布局、字体和渲染流程，区别只存在于 palette 数据。

## 背景与层级

- 背景采用三层大幅径向渐变，中心位于画布的 `(8%, 2%)`、`(105%, 48%)`、`(8%, 104%)`，让第一层光晕进入首屏、第二层穿过区块间隙、第三层从下方露出。椭圆半径分别为宽/高的 `(85%, 62%)`、`(90%, 65%)`、`(95%, 65%)`；不同长宽比和颜色范围形成柔和、不对称的光晕。
- 停点：0% / 20% / 50% / 80% / 100%，对应不透明度 0.78 / 0.702 / 0.351 / 0.0624 / 0。与初版相比，提高峰值浓度并延缓衰减，让浅色主题也能看出色团。各层复合在固定基底上；浓度受文字实际背景对比度约束，不是简单增大饱和度。
- Forest 光晕色 `#3D6854` / `#254653` / `#545B3E`；Lake `#79B9DA` / `#A6DCD9` / `#AABBE3`；Heather `#BD9BD9` / `#D5A9C5` / `#B0C2DD`；Sand `#DDB579` / `#DFAF99` / `#BDC5A4`；Rosewood `#754153` / `#514159` / `#625039`。浅色主题增加色团差异并加深次要文字/链接；深色主题提高次要文字/链接亮度，以保持渐变上的阅读对比度。
- Next 保留明确的主题色底；其余内容卡片使用不透明的底色。背景光晕主要从区块之间露出，文字区域不放高频图案。底部导航有固定底色，内容不穿透导航文字。
- 磨砂感通过柔和色团与固定细颗粒实现：128×128 灰度纹理使用固定随机种子 73219、透明度 6/255（约 2.35%），不随滚动重采样。这里是静态材质效果，不是实时采样卡片背后的内容做模糊。
- 截止日期、错误、冲突仍由文字/图标说明，不把主题色当作状态信息。每个 palette 完整指定 Material 的正文、容器、边框、强调与错误角色。三个偏浅主题的错误文字为 `#7F1D16`，两个偏深主题为 `#FFB4AB`；原生渐变对比度检查促使浅色错误文字进一步加深。

## 简单设置页

More → Settings → Appearance。只提供五个主题选项和 Fine texture（细纹理）开关。主题点击立即应用并保存，不需要 Apply。主题行显示名字、描述、色样和选中标记；整行可点击，支持大字体滚动与无障碍选择。

首版默认 Forest、细纹理关闭。普通设置开关、对话框、详情与所有标签页使用同一个 palette。SharedPreferences 仅保存主题 ID 与纹理开关，StateFlow 提供即时状态；未知主题 ID 回退 Forest。切换系统明暗不会替换它。固定深色主题需要浅色状态栏图标、固定浅色主题需要深色图标，该属性直接随 palette 配置，不创建额外主题选择状态。

## 背景预计算与缓存

背景静态地覆盖页面可视区域，列表内容在上方滚动。首次进入或切主题时，在后台准备渐变与固定纹理；准备期间先显示该主题的纯色基底。

使用较低分辨率 ARGB 位图缓存完整背景，长边固定 1024px，短边按 16px 量化，再平滑缩放到屏幕。1080×2400 比例生成 464×1024 位图，像素内存 1,900,544 字节（约 1.81MiB）；LRU 最多缓存两张，该比例下约 3.63MiB。方形尺寸的两张像素内存上限为 8MiB，另有约 64KiB 纹理块。被淘汰但仍显示的旧位图及 GPU 纹理不包含在这些数字中；不主动 recycle 显示中的位图。

缓存键包含主题 ID、纹理开关及量化宽高。背景在 `Dispatchers.Default` 生成，同一键复用位图；第三个键进入时淘汰最旧条目。尺寸或主题变化时重新准备，准备期间显示新主题基底；普通重组、下拉刷新和列表滚动复用缓存。缓存仅存在于进程内，应用更新/重启后重建，没有磁盘缓存和独立算法版本键。纹理块按需初始化一次，不执行每帧 CPU 模糊或随机纹理更新。

原生验收：五套颜色与设置页截图已检查；75 组关键 Material 前景/底色组合至少 4.5:1。五套原生背景开启纹理后，每 32px 抽样检查正文、次要文字、链接与错误色均至少 4.5:1；这不是所有尺寸/像素的穷尽检查。设备测试验证设置保存与重建、切换系统明暗保持颜色、1.8 倍字体、背景复用/淘汰/固定纹理和实际招呼语文字颜色；设置页不触发刷新。尚未测量滚动帧时间、GPU 总内存和背景生成耗时。

## 草案预览检查

已检查五套颜色与设置页的可交互预览、细纹理开关、主题选择同步、详情和 Coursework 跳转；320px 浏览宽度下没有横向溢出。调整渐变后，35 组关键纯色文字/底色组合对比度最低约 8.52:1；浏览器预览中直接位于渐变上的首页文字，通过隐藏前景、保留背景与纹理的截图，在原文字矩形范围逐像素检查底色，最低约 4.93:1。此处数字来自浏览器草案；原生验收范围与结果见上文及 [validation.md](validation.md)。
