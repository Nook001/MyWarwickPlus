# 颜色主题设计草案

状态：设计阶段，尚未接入 Android 应用。日期：2026-10-04。当前应用版本仍为 0.5.1。

每个主题是一套完整固定配色，直接决定画面的明暗。设置不提供浅色/深色/跟随系统开关，不读取系统明暗状态来转换已选配色，也不使用系统动态颜色覆盖主题。五套颜色共用布局、字体和渲染流程，区别只存在于 palette 数据。

## 背景与层级

- 背景采用三层大幅径向渐变，中心位于画布的 `(8%, 2%)`、`(105%, 48%)`、`(8%, 104%)`，让第一层光晕进入首屏、第二层穿过区块间隙、第三层从下方露出。椭圆半径分别为宽/高的 `(85%, 62%)`、`(90%, 65%)`、`(95%, 65%)`；不同长宽比和颜色范围形成柔和、不对称的光晕。
- 停点草案：0% / 20% / 50% / 80% / 100%，对应不透明度 0.78 / 0.702 / 0.351 / 0.0624 / 0。与初版相比，提高峰值浓度并延缓衰减，让浅色主题也能看出色团。各层复合在固定基底上；浓度受文字实际背景对比度约束，不是简单增大饱和度。
- Forest 光晕色 `#3D6854` / `#254653` / `#545B3E`；Lake `#79B9DA` / `#A6DCD9` / `#AABBE3`；Heather `#BD9BD9` / `#D5A9C5` / `#B0C2DD`；Sand `#DDB579` / `#DFAF99` / `#BDC5A4`；Rosewood `#754153` / `#514159` / `#625039`。浅色主题增加色团差异并加深次要文字/链接；深色主题提高次要文字/链接亮度，以保持渐变上的阅读对比度。
- Next 保留明确的主题色底；其余内容卡片使用平静、接近不透明的底色。背景光晕主要从区块之间露出，文字区域不放高频图案。底部导航有固定底色，内容不穿透导航文字。
- 磨砂感先通过柔和色团与固定细颗粒实现：小纹理块使用固定随机种子、约 2.5% 强度，不随滚动重采样。这里是静态材质效果，不是实时采样卡片背后的内容做模糊。
- 截止日期、错误、冲突仍由文字/图标说明，不把主题色当作状态信息。实现时为每个 palette 补齐 Material 的 onPrimary、边框、容器和错误状态色，逐组校验，而非保留默认的其他色系。

## 简单设置页

More → Settings → Appearance。只提供五个主题选项和 Fine texture（细纹理）开关。主题点击立即预览并保存，不需要 Apply。主题行显示名字、色样和选中标记；主题页可提供 Next 缩略预览。

首版默认 Forest。普通设置开关、对话框、详情与所有标签页使用同一个 palette。当前用户的选择持久化；切换系统明暗不会替换它。固定深色主题需要浅色状态栏图标、固定浅色主题需要深色图标，该属性直接随 palette 配置，不创建额外主题选择状态。

## 背景预计算与缓存计划

背景静态地覆盖页面可视区域，列表内容在上方滚动。首次进入或切主题时，在后台准备渐变与固定纹理；准备期间先显示该主题的纯色基底。

计划使用一张较低分辨率位图缓存完整背景，长边约 1024px，再平滑缩放到屏幕。以 1080×2400 屏幕为例，约 461×1024 的 ARGB 位图约 1.8MiB；缓存最多两张，避免为全部主题常驻十张背景。实际还需计入 GPU 纹理等内存，并在实现时测量。

缓存键包含主题 ID、纹理开关、目标宽高比例/尺寸档与背景算法版本。尺寸或主题变化时重新准备；普通重组、下拉刷新和列表滚动复用缓存。第一版先用有界内存缓存，暂不增加磁盘缓存与失效管理。背景纹理只生成一次，不执行每帧 CPU 模糊或随机纹理更新。

落地后验收：五套颜色的真实屏幕效果、正文与次要文字实际复合背景对比度、系统栏图标、大字体、切主题后持久化、滚动与刷新帧时间、后台生成耗时及缓存内存。目前这些原生性能与完整 Material 色组验收尚未执行。

## 草案预览检查

已检查五套颜色与设置页的可交互预览、细纹理开关、主题选择同步、详情和 Coursework 跳转；320px 浏览宽度下没有横向溢出。调整渐变后，35 组关键纯色文字/底色组合对比度最低约 8.52:1；浏览器预览中直接位于渐变上的首页文字，通过隐藏前景、保留背景与纹理的截图，在原文字矩形范围逐像素检查底色，最低约 4.93:1。五套完整配色截图已检查。这是本次预览、尺寸与默认浓度的检查，完整 Material 色组、其他页面/尺寸及原生渲染仍需落地后复核。
